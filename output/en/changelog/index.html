Changelog

The public, append-only record of substantive changes to the TourVsTravel reference system.

How this record works

Entries are never edited or removed; corrections are new entries referencing the superseded one. Each entry cites its decision identifier in the repository's decision log.

A reference system that changes silently cannot be cited safely. This page exists so that TourVsTravel never changes silently.

2026-07-03 — TSO v1, TDIS v1, and the machine layer published

The Travel Structure Ontology (TSO) v1 and the Travel Decision Integrity Standard (TDIS) v1, including the Structure Fit Protocol, received canonical public pages in seven languages. Versioned machine-readable endpoints were published so AI agents can read the same definitions humans read.

Decision: D-004

2026-07-03 — Public governance layer established

Standing rules (GOVERNANCE.md) and an append-only decision log (DECISIONS.md) were added to the repository. Substantive changes to the ontology, standard, public claims, routes, or monetization now require a logged decision.

Decision: D-003

2026-07-03 — Unverifiable destination-count claim retired

A destination-count figure was removed from public copy in all seven languages because no published destination pages backed it. Public numbers now use only build-verified counts, and a claims-restraint gate fails the build if a retired claim reappears.

Decision: D-002

2026-07-03 — Category Intelligence Factory plan adopted

The governing development plan was adopted. The asset's target state is a governed reference system for Travel Decision Architecture: a named ontology, a named standard, an operating protocol, machine-readable endpoints, and a public governance record.

Decision: D-001
