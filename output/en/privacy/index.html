Privacy

TourVsTravel is a static reference site. We do not collect personal data, run user accounts, process payments, or operate advertising networks.

Static site architecture

This site is statically generated from source files and served from GitHub Pages. There is no application server, no database, no session management, and no server-side processing of user requests. Every page you receive is a pre-built HTML file.

No accounts

TourVsTravel has no user registration, no login, no saved preferences, and no subscription system. There is no account of any kind to create or maintain.

No transactions

This site does not process payments, handle billing information, or connect to payment gateways. No financial data of any kind passes through this infrastructure.

No tracking or advertising

We do not set tracking cookies, use advertising networks, run analytics pixels, or share data with third-party ad platforms. Note: GitHub Pages, which hosts this site, is governed by GitHub’s own privacy policy. Their infrastructure processes HTTP requests to serve these files, subject to their terms.

Interactive tools

Comparison tools and calculators on this site run entirely in your browser as client-side JavaScript. No input you provide to these tools is transmitted to any server. Data stays local to your browser session and is discarded when you navigate away.

Future changes

If this site’s privacy posture ever changes—for example, if analytics or server-side features were added—this page will be updated before those changes take effect, not after.

Questions

For privacy-related questions, use the contact page.
