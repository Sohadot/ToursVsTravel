旅行構造オントロジー（TSO）v1

TourVsTravel リファレンスシステム全体で使用される17の旅行構造の正規分類。

旅行構造とは、安定した運用上の意味を持つ意思決定構造であり、マーケティングのラベルではない。このオントロジーは、クラス、それらを測定する軸、そして両者を安定に保つ規則を定義する。

このオントロジーとは

旅行構造オントロジーは、旅がどのように構築されるかを分類するために TourVsTravel が使用する17の構造を定義する。システム内のすべての比較ページ、意思決定ツール、参照文書はこれらのクラスに帰着する。オントロジーはシステムの真実の源であり、ページはそれを実装するのであって、再解釈するのではない。

各クラスは、それが何であるか、何でないか、そしてシステムの比較基準の下でどのように振る舞うかによって定義される。クラスは意味が決して変わらない安定した識別子を持つ。

6つの構造軸

すべての構造は、宣言された尺度を持つ6つの軸でプロファイルされる。軸はこのカテゴリーの座標系であり、2つの旅行形式を好みに還元することなく比較可能にする。

  • 構造強度 — 旅程のどれだけが事前に固定されているか。 structure_intensity
  • 自律性レベル — 旅行者が道中の意思決定にどれだけの裁量を保つか。 autonomy_level
  • サポートレベル — その形式にどれだけの運用サポートが組み込まれているか。 support_level
  • ペースプロファイル — 旅の時間が固定的か、均衡的か、柔軟か。 pace_profile
  • 没入プロファイル — 場所との接触が表層的か、均衡的か、深いか。 immersion_profile
  • 予測可能性プロファイル — 不確実性が旅行者に届く前に、その形式がどれだけ吸収するか。 predictability_profile

ベースラインスコアの読み方

ベースラインスコアは構造的な事前値であり、評決ではない。目的地と旅行者の文脈が適用される前に、構造がどのように振る舞う傾向があるかを記述する。公開されるすべての比較はそれを文脈化しなければならず、オントロジーは事前値を普遍的な答えとして扱うことを禁じる。

バージョン管理と引用

このオントロジーは追記専用である。クラスと軸が黙って改名・削除されることはなく、実質的な変更はすべてバージョン管理され、公開変更履歴に記録される。クラスの引用形式：TSO v1 / guided-group-tour。

機械可読アクセス

完全なオントロジーはバージョン管理された JSON アーティファクトとして /ontology/tso-v1.json で公開され、各クラスは /api/structures/{slug}.json で公開される。マシンレイヤーはこれらのページと一対一で対応し、エージェントも人間も同じ真実を読む。

17の構造

各クラスは完全なリファレンスページにリンクする。以下のラベルと定義はオントロジーのデータセットから直接描画されている。このページは真実の源をそのまま表示するのであり、言い換えるのではない。

ガイド付き団体旅行 行程、調整、主要な手配をオペレーターまたはガイド付きプログラムが担う、あらかじめ構造化された旅行形式。 引用形式: TSO v1 / guided-group-tour 独立旅行 旅行者自身が計画、予約、順序、日々の判断を管理し、ツアー枠組みに支配されない自己主導型の旅行構造。 引用形式: TSO v1 / independent-travel 一人旅 主に一人で行う旅行形式で、旅行者が自律性と意思決定負荷の両方をグループ支援なしで担う。 引用形式: TSO v1 / solo-travel バックパッキング 軽装・予算重視・高自律の旅行形式で、快適性や支援よりも柔軟性、ルート適応、価値密度を優先する。 引用形式: TSO v1 / backpacking ラグジュアリー旅行 快適性、サービス品質、摩擦の低減、高水準のキュレーションされた提供を重視するプレミアム旅行形式。 引用形式: TSO v1 / luxury-travel 家族旅行 複数人の調整、年齢構成の多様性、実務的な利便性、摩擦低減の必要性によって形づくられる旅行構造。 引用形式: TSO v1 / family-travel アドベンチャー旅行 挑戦、身体的関与、新規性、地形への接触、限界条件を、容易さや日常的快適性より優先する目的主導型の旅行形式。 引用形式: TSO v1 / adventure-travel 再生型・コミュニティ主導の旅行 相互的な地域利益、低い収奪性、コミュニティの主体性と場所の保全との整合を重視する価値主導型の旅行形式。 引用形式: TSO v1 / regenerative-community-led スロートラベルと静かな滞在 急がず、収奪性も低い旅行形式で、移動回数の少なさ、回復的なリズム、場所との持続的な接触を重視する。 引用形式: TSO v1 / slow-travel-quietcations 文化没入とホームステイ 文化的な質感、生活された地域文脈、標準的な宿泊観光より密接なホストとゲストの関係を求める深接触型の旅行形式。 引用形式: TSO v1 / cultural-immersion-homestay 祖先・レガシー旅行 血統、アイデンティティ、家族の記憶、受け継がれた場所とのつながり、世代間の意味を中心とする目的主導型旅行形式。 引用形式: TSO v1 / ancestry-legacy-travel 変容・ウェルネス旅行 回復、個人のリセット、内面的な取り組み、癒やしの習慣、構造化されたウェルビーイング成果を重視する目的主導型の形式。 引用形式: TSO v1 / transformational-wellness ロードトリップと自動運転旅行 ルートの制御、立ち寄り順、時間的柔軟性を、自ら運転・移動する地上交通に基づいて構成する移動主導型の旅行構造。 引用形式: TSO v1 / road-trip-self-drive クルーズ体験 輸送、宿泊、管理された旅程リズムを船という中心構造に統合した、高度に一体化された支援重視の旅行形式。 引用形式: TSO v1 / cruise-experience エコ・サステナブル旅行 環境への害を減らし、収奪的な行動を抑え、旅行の選択を持続可能性の原則に整合させることを目指す価値主導型の旅行形式。 引用形式: TSO v1 / eco-sustainable-travel 宗教・精神的巡礼 一般的な余暇最適化ではなく、信仰、儀礼、聖なる義務、精神的鍛錬、超越的意味を中心に組織される目的主導型の旅行形式。 引用形式: TSO v1 / religious-spiritual-pilgrimage 聖地・聖人観光 聖地、聖人、聖遺物、聖墓、あるいは信仰・記憶・遺産が交差する局所的な崇敬地理を中心とする聖域志向の旅行形式。 引用形式: TSO v1 / shrine-saints-tourism
